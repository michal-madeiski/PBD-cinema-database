# 🎬 Cinema Database Project

### 📌 Project Overview
The Cinema Database Project is a group project developed by a four-person team as part of the Database Design course in the Applied Computer Science program at Wroclaw University of Science and Technology.

The main goal of the project is to design and implement a relational database for a cinema network management system. During the development process, the project scope was extended to include an additional feature: group tickets.

---

### 🎯 Project Objectives
- Design a normalized relational database for a cinema network.

- Ensure data integrity and consistency using constraints and relations.

- Seed the database with realistic, generated sample data for testing and demonstration purposes.

- Extend the system with group ticket support.

- Prepare example queries to demonstrate typical operations.

- Create indexes to optimize query performance.

---

### ▶️ Running the Project
1. database/cinema_db_sql - create database
   
2. seeder.py - seed the databse with sample data
   
3. database/cinema_db_alter.sql - extend the database with group ticket
   
4. database/indexes.sql (uncomment lines: 9-24) - create indexes
   
5. sample_queries/*.sql - run sample queries
